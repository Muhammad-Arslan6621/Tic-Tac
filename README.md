# Tic-Tac

A simple and interactive **Tic-Tac-Toe game** built with HTML, CSS, and JavaScript.

The project focuses on creating a browser-based game with an interactive interface, game logic, sound effects, and visual feedback.

## 🎮 Features

* Interactive Tic-Tac-Toe gameplay
* Player turn handling
* Win and game-over detection
* Restart/new game functionality
* Interactive user interface
* Game sound effects
* Background music
* Visual feedback for game events
* Responsive design

## 🛠️ Technologies Used

* **HTML5** – Page structure and game layout
* **CSS3** – Styling, animations, and responsive design
* **JavaScript** – Game logic and user interactions
* **MP3 Audio** – Game sounds and background music
* **GIF** – Visual game feedback

## 📁 Project Structure

```text
Tic-Tac/
│
├── index.html          # Main game page
├── style.css           # Game styling and layout
├── script.js           # Game logic and interactions
├── music.mp3           # Background music
├── ting.mp3            # Game interaction sound
├── gameover.mp3        # Game-over sound
└── excited.gif         # Visual feedback
```

## 🚀 How to Run

1. Clone the repository:

```bash
git clone https://github.com/Muhammad-Arslan6621/Tic-Tac.git
```

2. Open the project folder.
3. Open `index.html` in any modern web browser.
4. Start playing.

No additional installation or dependencies are required.
